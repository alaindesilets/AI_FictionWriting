# Translation Prompt — Alain Désilets Fiction

## Task

I would like you to translate one of my short stories from French to English.

- **Path to the story file:** L'arnaque du siècle.pdf
- **Source language:** French
- **Target language:** English
- **Output file:** writing-sampples-and-guidelines/sample-stories/L'arnaque du siècle - EN.md

---

## Reference Documents

Before beginning, read the following documents in full. They are contained inside this project.

- **translation-guide.md**. Outlines the translation process you should follow to ensure that the translation reads as an idiomatic text that could have been written directly in English. It also outlines some common linguistic traps to be avoided
translation-guide-fr-to-en.md]
- ****sample-stories**. This **english** and **french** subfolders contain all the stories I have written to date. Use these as examples of my writing stule. All of those are source language files. They weren't translated from the other language. Note that some of the stories may be incomplete.


---


## Output Format

- Produce the complete translated text as a single file in MD format.
- Preserve the original document structure: title, author credit, section breaks, formatting.
- Append a **Translation Notes** section at the end of the file documenting: difficult passages and the solutions chosen, terminology decisions, any significant departures from the source text and the reason for them.

## Time budget

Take your time. Quality is more important than time.

If it takes you an hour or even more, so be it.
