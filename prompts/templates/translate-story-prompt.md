# Translation Prompt — Alain Désilets Fiction

## Task

I would like you to translate one of my short stories from [SOURCE LANGUAGE] to [TARGET LANGUAGE].

- **Path to the story file:** [STORY FILE NAME]
- **Source language:** [SOURCE LANGUAGE]
- **Target language:** [TARGET LANGUAGE]
- **Output file:** [PATH TO OUTPUT FILE]

---

## Reference Documents

Before beginning, read the following documents in full. They are contained inside this project.

- **translation-guide.md**. Outlines the translation process you should follow to ensure that the translation reads as an idiomatic text that could have been written directly in [TARGET LANGUAGE]. It also outlines some common linguistic traps to be avoided
translation-guide-fr-to-en.md]
- ****sample-stories**. This **english** and **french** subfolders contain all the stories I have written to date. Use these as examples of my writing stule. All of those are source language files. They weren't translated from the other language. Note that some of the stories may be incomplete. Don't look at the **translations** folder!! These are translations of a story originally written in the other language. So their style may not be perfectly native, as it may have been influenced by the source language version.


---


## Output Format

- Produce the complete translated text as a single HTML file, to facilitate printing. Use the simplest HTML format you can (no complicated CSS styles).
- Preserve the original document structure: title, author credit, section breaks, formatting.
- Append a **Translation Notes** section at the end of the file documenting: difficult passages and the solutions chosen, terminology decisions, any significant departures from the source text and the reason for them.

## Time budget

Take your time. Quality is more important than time.

If it takes you an hour or even more, so be it.
