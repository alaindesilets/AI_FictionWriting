# Expeeriments in AI fiction writing

This project contains the framework used by Alain Désilets to generate short stories with AI in a semi autonomous fasshion. Also for translating them bettween French and English (in either direction).

It is is designed with **coding** agent (Claude Code, copilot) in mind, as opposed to the more generic LLM models that are available on the web interface of those products.

Asking a coding agent to write or translate short fiction may seem a strange choice, given that those are trained to have a very terse, technical and precise writing style.
